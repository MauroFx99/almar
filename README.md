# AlMar 🌊

> Hecho para llevar el mar contigo.

Web de **AlMar**, tienda de moda y accesorios para mujer en Tolú, Colombia.

🔗 **Ver la web:** https://almar-showroom.netlify.app

![Portada de AlMar](imagenes/portada.jpg)

## Secciones
- Portada con botón de WhatsApp
- Productos: bolsos, blusas, accesorios y maquillaje
- Galería de pulseras
- Sobre nosotros
- Contacto con mapa de Google
- Botón flotante de WhatsApp

## Tecnologías
| Herramienta | Para qué |
|---|---|
| HTML | Estructura y contenido |
| CSS | Diseño: colores, Grid, Flexbox |
| Git y GitHub | Control de versiones |
| Netlify | Publicación automática con cada `git push` |

## Cómo verla en tu computadora
1. Descarga o clona este repositorio.
2. Abre `index.html` en el navegador.
